# Анализ качества кредитного портфеля

## О проекте

Проект разработан для анализа качества кредитного портфеля банка и мониторинга ключевых показателей риска.

На основе данных DWH подготовлены SQL-витрины для анализа выдач, состояния кредитного портфеля, просроченной задолженности, РППУ, FPD, Vintage и Roll Rate. На основе подготовленных данных разрабатывается дашборд для визуализации и анализа результатов в Power BI

## Данные

В основе проекта используются реальные данные кредитного портфеля. Для демонстрации проекта в открытом доступе числовые показатели были изменены и не соответствуют фактическим значениям.

Персональные данные клиентов и сотрудников в проекте не используются.

## Реализованные аналитические витрины

### Выдачи кредитов
Формирование витрины по выданным кредитам с определением статуса клиента (новый/повторный), суммы и параметров кредита.

### Кредитный портфель
Ежедневные срезы кредитного портфеля с остатками по основному долгу, процентам, просрочке и ответственным сотрудникам.

### РППУ
Анализ резервов по кредитам с детализацией по категориям классификации и основаниям формирования резервов.

### FPD (First Payment Default)
Определение факта возникновения просрочки после первого платежа по графику.

### Vintage Analysis
Когортный анализ качества кредитов по месяцам выдачи с расчетом показателей по возрасту кредита (MOB).

### Roll Rate Analysis
Анализ переходов кредитов между бакетами просрочки для оценки динамики кредитного риска.
