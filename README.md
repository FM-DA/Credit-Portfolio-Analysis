# Анализ качества кредитного портфеля

## О проекте

Проект посвящен анализу качества кредитного портфеля банка и мониторингу ключевых показателей кредитного риска.

В рамках проекта:

- с помощью SQL подготовлены аналитические витрины на основе данных кредитного портфеля;
- разработаны расчеты показателей качества портфеля: PAR, РППУ, FPD, Vintage и Roll Rate;
- с помощью Python (pandas) автоматизирована подготовка и выгрузка данных для обновления аналитических витрин;
- в Power BI разработан дашборд для анализа портфеля, качества выдач и динамики кредитного риска.

## Данные

В основе проекта использованы данные кредитного портфеля банка. Для публикации в открытом доступе числовые показатели были изменены и не соответствуют фактическим значениям.

Персональные данные клиентов и сотрудников не используются.

## Используемые инструменты

- **PostgreSQL / SQL** — извлечение данных, подготовка аналитических витрин и расчет показателей;
- **Python / pandas** — автоматизация подготовки и выгрузки данных;
- **Power BI** — разработка аналитического дашборда;
- **DAX** — расчет мер и показателей в модели Power BI.

## Реализованные аналитические витрины

### Выдачи кредитов

Формирование витрины по выданным кредитам с расчетом основных параметров выдачи.

Витрина используется для анализа объема и структуры выдач, динамики кредитования, а также распределения выдач по продуктам и подразделениям.

### Кредитный портфель

Формирование витрины текущего кредитного портфеля на дату среза с детализацией по основному долгу, начисленным процентам, просрочке, продуктам и подразделениям.

На основе данных рассчитываются показатели PAR1, PAR30 и PAR90, позволяющие анализировать объем и структуру просроченной задолженности.

### РППУ

Формирование витрины по резервам на возможные потери по кредитам с классификацией задолженности по категориям РППУ.

Витрина используется для анализа объема и структуры резервов, а также распределения кредитов по категориям качества.

### FPD (First Payment Default)

Формирование витрины для определения возникновения просрочки после первого платежа по графику.

Показатель используется для оценки качества новых выдач и сравнения качества кредитов различных периодов выдачи.

### Винтажный анализ

Формирование когортной витрины по месяцам выдачи кредитов с расчетом показателей качества портфеля в зависимости от возраста кредита (MOB).

Винтажный анализ позволяет сравнивать качество различных когорт выдач с учетом продолжительности периода наблюдения.

### Roll Rate

Формирование витрины переходов кредитов между стадиями просрочки: 0, 1–30, 31–60, 61–90 и 90+ дней.

Анализ используется для оценки динамики миграции задолженности между категориями просрочки и изменения структуры кредитного риска.

## Ключевые метрики

- **Объем кредитного портфеля** — текущий объем задолженности по кредитам.
- **PAR1** — объем задолженности с просрочкой от 1 до 30 дней.
- **PAR30** — объем задолженности с просрочкой от 31 до 90 дней.
- **PAR90** — объем задолженности с просрочкой более 90 дней.
- **FPD (First Payment Default)** — доля кредитов, по которым возникла просрочка после первого платежа.
- **РППУ** — объем резервов по кредитному портфелю и их структура по категориям качества.
- **Roll Rate** — переходы кредитов между диапазонами просрочки: 0, 1–30, 31–60, 61–90 и 90+ дней.

## Основные выводы

- **Кредитный портфель** вырос на **18,5%** за период и достиг **44,84 млрд сом**. Одновременно доля просроченного портфеля увеличилась с **4,6% до 7,79%**.

- Наиболее заметный рост проблемной задолженности наблюдался в **PAR1 и PAR30**: к концу периода они составили **983 млн и 759 млн сом**, увеличившись на **95,7% и 133,2%** соответственно. **PAR90 вырос на 91,6%** и достиг **1,75 млрд сом**.

- **«Онлайн кредит для МП»** является крупнейшим источником проблемной задолженности: на него приходится около **38% PAR1, 50% PAR30 и 51% PAR90**. При этом он также является крупнейшим продуктом по объему выдач — **15,37 млрд сом**.

- **РППУ вырос на 83,3%**, до **3,42 млрд сом**. В структуре резервов преобладают **потери (57,5%)** и **субстандартные активы (22,6%)**.

- Объем выдач составил **48,33 млрд сом**, снизившись на **8,5%**. Доля новых клиентов снизилась примерно с **24% до 19,3%**, поэтому в структуре выдач выросла роль повторных клиентов.

- **FPD демонстрировал снижение**: доля кредитов с FPD снизилась с **15,81% в июле 2025 года до 10,88% в июне 2026 года**. Это может свидетельствовать об улучшении качества новых выдач в последние месяцы.

- **Винтажный анализ** показывает увеличение PAR30 и PAR90 по мере роста возраста кредита (MOB). Более поздние винтажи имеют более короткий период наблюдения, поэтому их итоговое качество пока нельзя напрямую сравнивать со старыми винтажами.

- **Roll Rate** показывает увеличение концентрации задолженности в бакете **90+ дней**, что согласуется с ростом PAR90 и указывает на накопление более глубокой просрочки.

### Итог

За рассматриваемый период кредитный портфель вырос, однако его рост сопровождался **ухудшением качества портфеля и существенным увеличением просроченной задолженности**, особенно в сегменте онлайн-кредитования. Одновременно снижение FPD в последних месяцах может свидетельствовать об **улучшении качества новых выдач**.
